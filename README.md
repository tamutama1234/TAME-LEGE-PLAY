# TAME&LEGE PLAY

**KEEP UP. KEEP PLAYING.**

An Android audio and video player starter built with Kotlin, Android Studio, and AndroidX Media3 (ExoPlayer).

## Current starter features

- Choose one audio or video file using Android's system document picker.
- Play supported local media with ExoPlayer.
- Built-in playback controls plus Play, Pause, and Stop buttons.
- Video display through Media3 PlayerView.
- Dark interface with gold TAME&LEGE PLAY branding.

## Open in Android Studio

1. Download or clone this repository.
2. Open the project folder in Android Studio.
3. Allow Gradle sync to finish.
4. Run the `app` configuration on an Android device or emulator.

The project uses JDK 17 and Android SDK 36. Android Studio may prompt you to install the required SDK components.

## Current limitations

- This is the first playback foundation, not a finished APK.
- Background playback with a MediaSession foreground service is the next development step.
- Playlist/library scanning, video-to-audio conversion, and the faith-themed visualizer are not included yet.
- Playback depends on the media formats supported by the device and the bundled Media3 decoders.
